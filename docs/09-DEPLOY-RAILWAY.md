# 9. النشر على Railway (من الآيباد أو أي متصفح)

المشروع مهيأ لـ Railway: يكتشف المنصة تلقائياً (وضع الإنتاج، ملفات تعريف آمنة، قراءة IP الحقيقي)، ويحفظ قاعدة البيانات والصور على القرص الدائم (Volume) إن وُجد.

## الخطوات
1. ادخل railway.com وسجّل الدخول بحساب GitHub.
2. **New Project ← Deploy from GitHub repo** واختر المستودع.
3. بعد أول بناء: أضف **Volume** للخدمة، ومسار التركيب `/data`. (بدونه تضيع البيانات عند كل إعادة تشغيل.)
4. **Variables**:
   | المتغير | القيمة | الغرض |
   |---|---|---|
   | `ADMIN_EMAIL` | بريدك | من يسجل بهذا البريد يصبح مديراً عاماً |
   | `SEED_DEMO` | `1` (اختياري) | بيانات تجريبية وهمية عند أول تشغيل فقط |
   | `AI_PROVIDER` / `AI_API_KEY` | اختياري | المساعد المتقدم |
5. **Settings ← Networking ← Generate Domain** ← افتح الرابط وسجّل ببريد `ADMIN_EMAIL`.
6. لاحقاً: **Custom Domain** لربط نطاقك (مثل wasmcamels.com).

## ملاحظات
- لا تُمنح صلاحية الإدارة لأي حساب تجريبي في الإنتاج.
- أي `git push` على الفرع الرئيسي يعيد النشر تلقائياً، والبيانات على الـ Volume تبقى.
- النسخ الاحتياطي: Railway يدعم لقطات للـ Volume من إعداداته.
