# 4. الهوية البصرية

**الاسم:** وسم | WASM — **الشعار اللفظي:** «السوق الخليجي لأهل الإبل»

## الشعار
`public/img/logo.svg` — سنامان متصلان بخط واحد على هيئة **وسم** الإبل، مع "عصا" عمودية ونقطة، بتدرج ذهبي رملي داخل مربع زمردي بزوايا ناعمة. يعمل بحجم 16px (أيقونة المتصفح) حتى الشاشات الكبيرة.
> ملاحظة: الشعار الحالي مبدئي قابل للتشغيل. يُنصح بمراجعته مع مصمم هوية قبل التسجيل كعلامة تجارية.

## الخطوط
- **العناوين:** Reem Kufi (كوفي عصري فخم)
- **النصوص:** IBM Plex Sans Arabic (وضوح عالٍ لكل الأعمار)
- بدائل تلقائية عند عدم توفر الإنترنت: Noto Sans Arabic / Tahoma.

## مبادئ الواجهة
1. **RTL أولاً** باستخدام خصائص CSS المنطقية (`inline-start/end`) لتسهيل دعم الإنجليزية لاحقاً.
2. **لكل الأعمار:** خط أساسي 16px، أهداف لمس ≥ 44px، تباين عالٍ، أفعال واضحة بالعربية.
3. **الصدق في البيانات:** شارات تميّز «من سجلاتك» عن «تقديري» عن «مسودة الذكاء الاصطناعي»، وتنبيه دائم أن المواعيد تقديرية.
4. **الجوال:** شريط تنقل سفلي مع زر المساعد في المنتصف.
5. **الصور:** الصور التجريبية الحالية رسوم توضيحية مولدة ومكتوب عليها "تجريبي". يُنصح بجلسة تصوير احترافية لإبل حقيقية (بإذن ملاكها) للصفحة التسويقية.
