# 6. الأمان والخصوصية

## منفذ الآن (ومُختبر)
| المتطلب | التنفيذ |
|---|---|
| حماية الحسابات | كلمات مرور بـ scrypt (N=16384) وملح عشوائي؛ سياسة ≥10 أحرف مع أرقام وحروف؛ قفل 15 دقيقة بعد 5 محاولات؛ حد معدل للدخول والتسجيل؛ رسائل خطأ عامة لا تكشف وجود الحساب |
| الجلسات | رمز عشوائي 256-bit يُخزن **كتجزئة** فقط؛ كوكي HttpOnly + SameSite=Strict + Secure (إنتاج)؛ تغيير كلمة المرور ينهي الجلسات الأخرى |
| CSRF | SameSite=Strict + ترويسة مخصصة إلزامية لكل طلب كتابة |
| XSS | CSP صارم (`script-src 'self'`، بلا سكربتات مضمنة)؛ تهريب كل المخرجات في الواجهة؛ `X-Content-Type-Options`؛ `X-Frame-Options: DENY` |
| عزل البيانات | كل استعلام مقيد بـ `owner_id`؛ الوصول لمطية الغير يعيد 404 (لا يكشف الوجود)؛ لا ربط نسب عبر حسابات؛ المساعد يستخدم نفس القيود. في PostgreSQL: RLS كطبقة ثانية |
| الصلاحيات | 8 أدوار؛ الأدوار الإدارية لا تُمنح ذاتياً؛ جدول `admin_country_scopes` لصلاحيات كل مدير دولة (م3) |
| سجل التدقيق | كل إنشاء/تعديل/حذف/رفع/مشاركة/دخول — مع الفروقات وعنوان IP. في PostgreSQL: قواعد تمنع تعديله أو حذفه |
| الملفات | فحص النوع من البايتات الفعلية لا من الامتداد؛ حد 5MB؛ أسماء عشوائية خارج مجلد الويب؛ تُخدم فقط بعد التحقق من الملكية أو رمز مشاركة صالح؛ أذونات 0600 |
| روابط المشاركة | رمز 192-bit مخزن كتجزئة؛ نطاق محدد؛ انتهاء إلزامي (≤90 يوماً)؛ إلغاء فوري؛ لا تكشف المالك أو الموقع أو الملاحظات أو المبالغ أو المستندات |
| الموقع والملكية | لا تُحفظ إحداثيات للعزب (وصف عام فقط)؛ النسب والملكية "غير موثقة" افتراضياً |
| الذكاء الاصطناعي | لا كتابة دون تأكيد صريح؛ لا أدوات مالية أو مزايدة إطلاقاً؛ أدوات النموذج اللغوي للقراءة فقط وضمن حلال المستخدم؛ صور المستخدم لا تُستخدم للتدريب إلا بموافقة صريحة (معطلة افتراضياً) |
| الشركاء | لا مشاركة بيانات مع الشركات إلا بموافقة منفصلة (معطلة افتراضياً) |
| حق الوصول | تصدير JSON لكل بيانات المستخدم |
| الأخطاء | لا تُعرض تفاصيل الأخطاء الداخلية للمستخدم |

## مطلوب عند النشر
- **تشفير الاتصالات:** HTTPS إلزامي (Caddy يصدر شهادة Let's Encrypt تلقائياً — انظر `deploy/Caddyfile`)، مع `NODE_ENV=production` لتفعيل HSTS والكوكي الآمن.
- **النسخ الاحتياطية:** `scripts/backup.sh` يومياً عبر cron + نسخة خارج الخادم مشفرة (مثلاً R2/S3 مع تشفير).
- **الأسرار:** مفتاح مزود الذكاء الاصطناعي في `.env` بأذونات 600، لا يُرفع إلى Git.
- تحديث نظام التشغيل تلقائياً، جدار ناري يسمح فقط 80/443/SSH بالمفاتيح.

## قبل الإطلاق التجاري (مخطط)
- استعادة كلمة المرور بالبريد/SMS، ومصادقة ثنائية (OTP) — تتطلب مزود رسائل.
- مراجعة قانونية لسياسة الخصوصية وشروط الاستخدام وفق قوانين حماية البيانات في دول الخليج (مثل قانون قطر رقم 13 لسنة 2016 ونظام حماية البيانات الشخصية السعودي) — **نحن لسنا جهة قانونية ويلزم مستشار محلي.**
- قبل المزادات والمدفوعات: التحقق من متطلبات الترخيص في كل دولة، وبوابة دفع مرخصة، واختبار اختراق مستقل.
