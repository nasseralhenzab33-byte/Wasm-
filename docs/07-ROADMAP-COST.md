# 7. المهام المتبقية والتكلفة التقديرية لكل مرحلة

> **تحديث:** كل المراحل الأربع صارت مبنية كنسخة تشغيلية في هذا المستودع (ويب + خادم + قاعدة بيانات + اختبارات). الأرقام أدناه صارت تقديراً لما **بقي** لتحويل كل مرحلة إلى خدمة تجارية كاملة.

## ما بقي قبل الإطلاق التجاري (لكل المنصة)
| العمل | لماذا | تقدير |
|---|---|---|
| بوابة دفع مرخصة (للباقات الإعلانية) | الحملات حالياً تُفعّل يدوياً بعد الدفع | 3,000–8,000 ر.ق + رسوم البوابة |
| استعادة كلمة المرور + تأكيد البريد/الجوال (OTP) | يحتاج مزود بريد/SMS | 1,500–3,000 ر.ق |
| إشعارات خارج التطبيق (بريد/واتساب/Push) | الإشعارات الحالية داخل التطبيق وفورية | 2,000–5,000 ر.ق |
| الانتقال إلى PostgreSQL + تخزين صور سحابي | عند تجاوز بضعة آلاف مستخدم أو تعدد الخوادم | 5,000–9,000 ر.ق |
| تطبيق Flutter (iOS/Android) على نفس الـ API | اختياري — الموقع يعمل كتطبيق على الجوال | 30,000–60,000 ر.ق |
| مراجعة قانونية (الخصوصية، الشروط، تراخيص المزادات والوساطة في كل دولة) | إلزامي قبل المزادات التجارية | 5,000–15,000 ر.ق |
| اختبار اختراق مستقل | قبل التعامل بمبالغ كبيرة | 5,000–12,000 ر.ق |
| النسخة الإنجليزية | البنية جاهزة (RTL منطقي) | 4,000–8,000 ر.ق |

التقديرات الأصلية لكل مرحلة (أدناه) تبقى مرجعاً لو أردت إعادة بنائها بفريق كامل وبالتقنيات المقترحة (NestJS/Next.js/Flutter).


> **تنبيه مهم:** الأرقام أدناه تقديرات استرشادية لنطاقات سوق العمل الحر والوكالات الصغيرة في الخليج والمنطقة، وليست عروض أسعار. تختلف كثيراً حسب الفريق والدولة والجودة المطلوبة. احصل على عرضين أو ثلاثة قبل أي التزام.
> العملة: ريال قطري (ر.ق).

## المرحلة 1 — إدارة الحلال والمساعد (✅ النواة منفذة)
**منفذ:** حسابات مستقلة، ملف رقمي لكل مطية، تلقيح وولادة ومواليد وفطام وتحصينات وعلاجات وزيارات وبيع وشراء ونقل، شجرة نسب، تقويم، تنبيهات، صور ومستندات، مشاركة محدودة، سجل تعديلات، مساعد نصي خليجي يسجل بعد التأكيد، بنية مزودي AI، 18 مجموعة اختبار.

**المتبقي قبل الإطلاق العام:**
1. استعادة كلمة المرور بالبريد + تأكيد البريد/الجوال.
2. إشعارات فعلية (بريد/واتساب/Push) لمواعيد الولادة — حالياً تظهر داخل التطبيق.
3. صفحات قانونية (الخصوصية، الشروط) بمراجعة مستشار.
4. ربط مفتاح مزود ذكاء اصطناعي وتجربة الأسئلة المفتوحة.
5. اختبار ميداني مع 5–10 ملاك إبل حقيقيين، وتحسين مفردات المساعد حسب لهجاتهم.
6. النشر على خادم مع HTTPS ونسخ احتياطي يومي ومراقبة.
7. استيراد جماعي للحلال من Excel.
