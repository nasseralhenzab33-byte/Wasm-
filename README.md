# وسم | WASM — «السوق الخليجي لأهل الإبل»

منصة رقمية متخصصة في الإبل لدول الخليج الست. هذا المستودع يحتوي **نسخة تشغيلية لكل المراحل الأربع**:

| المرحلة | ما يعمل الآن |
|---|---|
| **1 — إدارة الحلال** | حسابات مستقلة، ملف رقمي لكل مطية، تلقيح وولادة ومواليد وفطام وتحصينات وعلاجات وبيع ونقل، شجرة نسب، أسماء الأعمار (حوار… سديس، بعير/فاطر)، تقويم، تنبيهات تلقائية، صور ومستندات، مشاركة برابط محدود، سجل تعديلات، المساعد WASM AI |
| **2 — السوق** | إعلانات (من ملف المطية مع وصف آلي من السجلات)، مراجعة قبل النشر، بحث وفلاتر (الدولة، السعر، الفئة، العمر، الجنس)، مفضلة، مشاركة، إبلاغ، مقارنة حتى 4 إعلانات، عروض سعر وعروض مضادة، رسائل خاصة، ملخص التفاوض، صفقات تُسجَّل في الحلال تلقائياً، اكتشاف الصور المكررة، توصيات |
| **3 — المزادات والشركاء** | مزادات مباشرة تُعالج على الخادم (معاملة متسلسلة، سجل إلحاقي بسلسلة تجزئة، تمديد ضد القنص، سعر أدنى سري)، بث مباشر (SSE)، إشعارات تجاوز المزايدة وقرب الانتهاء، تسجيل الفائز وإنشاء صفقة، رصد أنماط المزايدة غير المعتادة للمراجعة البشرية، الوسطاء، «شركاء وسم» (شركات، خدمات، باقات، حملات، رعاية أقسام، أكواد خصم، إحالات، عقود رعاية مع تذكير، تقارير ظهور ونقرات)، أدلة الخدمات البيطرية والأعلاف والنقل، لوحة إدارة بمدير عام ومديري دول |
| **4 — التوسع** | تثمين استرشادي من صفقات مكتملة فقط (لا يظهر بدون بيانات كافية)، توصيات، مجتمع أهل الإبل (منشورات، تعليقات، إعجاب، إبلاغ)، المزاين والنتائج مع ربط النتيجة بملف المطية |

> ⚠️ كل البيانات التجريبية (`*@wasm.demo`) **وهمية بالكامل** ومعلّمة بكلمة «تجريبي».

## التشغيل السريع (دقيقتان)
المتطلبات: **Node.js 22.5 أو أحدث** فقط. لا توجد مكتبات لتثبيتها (`npm install` غير مطلوب).

```bash
cd wasm
npm run seed     # إنشاء قاعدة البيانات + البيانات التجريبية
npm start        # http://localhost:3000
```
حسابات تجريبية (كلمة المرور لكلها **Wasm-demo-2026**):

| الحساب | الدور |
|---|---|
| demo@wasm.demo | مالك حلال (فيه حلال وإعلان) |
| buyer@wasm.demo | مشترٍ عنده تفاوض مفتوح |
| trader@wasm.demo | تاجر/بائع في السعودية |
| feed@wasm.demo | شركة أعلاف (لوحة الشريك) |
| broker@wasm.demo | وسيط موثّق |
| admin@wasm.demo | مدير عام (لوحة الإدارة) |

لإنشاء مدير للإنتاج: سجّل حساباً عادياً ثم نفّذ `node scripts/make-admin.js بريدك@example.com` (أو `--country QA` لمدير دولة).

جرّب في المساعد:
- `لقحت وضحى اليوم من شاهين`
- `متى لقحت وضحى؟`
- `أي النوق عندي بتولد الشهر القادم؟`
- `وش جابت وضحى آخر مرة؟`
- `ولدت الشعلة اليوم بنت وسميناها غلا`
- `أبي أبيع الشعلة`

## تفعيل الذكاء الاصطناعي المتقدم (اختياري)
المساعد يعمل بالكامل للأوامر المعروفة **بدون أي مزود خارجي**. لتفعيل الأسئلة المفتوحة وتحليل الصور (م2)، أضف إلى `.env`:
```
AI_PROVIDER=anthropic        # أو openai لأي واجهة متوافقة
AI_API_KEY=...
AI_MODEL=...                 # اختياري
```

## النشر على خادم (بأمر واحد)
على خادم Ubuntu 24.04 جديد، بعد ربط النطاق بعنوان الخادم:
```bash
apt-get update && apt-get install -y unzip && unzip wasm-phase1.zip
bash wasm/deploy/install.sh النطاق.com --demo     # --demo اختياري
```
يثبت Node.js 22 وCaddy (HTTPS تلقائي) والجدار الناري والنسخ الاحتياطي اليومي ويشغّل وسم كخدمة دائمة.
- التحديث لنسخة جديدة: `unzip -o wasm-phase1.zip && bash wasm/deploy/update.sh`
- حذف الحساب التجريبي: `bash /opt/wasm/deploy/remove-demo.sh`

### أو عبر Docker
```bash
docker build -t wasm .
docker run -d --name wasm -p 3000:3000 -v wasm-data:/data --env-file .env wasm
docker exec wasm node --disable-warning=ExperimentalWarning scripts/seed.js
```
ضع Caddy أو Nginx أمامه لـ HTTPS. **لا تشغّل الإنتاج بدون HTTPS.**
